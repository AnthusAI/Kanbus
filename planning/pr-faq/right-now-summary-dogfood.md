# Right-Now Summary Dogfood (real output from this board)

Captured by running `kbs now` against this project's own Kanbus board, with right-now summaries generated by GPT 5.6 Luna (pinned via `right_now.model` in `.kanbus.yml`). This exercises the full pipeline end-to-end: write-gate regen (Epic 5), hierarchical roll-up (Epic 3), and the `kbs now` feed (Epic 6).

## How the summaries were produced

1. Created a demo epic under the right-now summary initiative (`kbs-76a4c8`). The write gate regenerated the epic's right-now summary and propagated a regenerated summary up to the initiative (ancestor propagation).
2. Ran `kbs now` (flat, `--tree`, `--json`) to capture the feed.
3. Deleted the demo epic. The gate propagated a regeneration up to the initiative, so the initiative's summary refreshed to reflect that its child was removed.

All summaries below are real GPT 5.6 Luna output, not mocks.

## Bug found during dogfooding

`kbs-ec5db2` (priority 1): right-now summary writes do not sync to the `project/.overlay/issues` overlay, so new issues' summaries are shadowed in the feed. The dogfooding caught this: a new epic's summary existed on disk but showed "(no right-now summary)" in `kbs now` because a stale overlay copy shadowed it. Fix tracked in that issue.
